# Capturas de Puente

Estas imágenes muestran la interfaz real del proyecto, ejecutada en local con
una base D1 y un espacio KV de demostración aislados. No se usó la cuenta
personal del autor ni se modificó el despliegue público.

| Archivo | Vista | Tamaño del navegador |
| --- | --- | --- |
| `bandeja-escritorio.jpg` | Compositor, búsqueda y envíos de ejemplo. | 1440 × 1000 |
| `bandeja-movil.jpg` | Bandeja desplazada hasta los filtros y los envíos. | 390 × 844 |
| `seleccion-multiple.jpg` | Dos imágenes seleccionadas antes de enviar. | 390 × 844 |
| `acceso.jpg` | Pantalla de acceso actual con el formulario vacío. | 1440 × 1000 |

Las vistas móviles son capturas de navegador, no de un teléfono físico.
Las capturas se guardan directamente en JPEG, sin recrear ni retocar la interfaz.

## Contenido de ejemplo

- Cuenta `demo@example.com`, reservada para demostración local.
- Dos notas sobre continuar una tarea en otro dispositivo, una de ellas fijada.
- Enlace al repositorio público de Puente.
- Archivo de texto `ideas-del-proyecto.txt` con contenido ficticio.
- Ilustraciones geométricas originales `paisaje-demo.svg` y `costa-demo.svg`,
  sin imágenes ni datos personales de terceros.

## Cómo renovarlas

1. Seguir el arranque local del README, usando un directorio de estado exclusivo
   para la demostración con `--persist-to`, tanto al migrar como al arrancar Wrangler.
2. Crear una cuenta local con datos de ejemplo y preparar los envíos descritos.
   No configurar recursos remotos ni usar credenciales personales.
3. Capturar la aplicación con los tamaños indicados y esperar a que carguen
   las fuentes, las imágenes y los envíos. Mantener el formulario de acceso vacío.
4. En la bandeja móvil, desplazar la página hasta la búsqueda y los filtros.
   Para selección múltiple, elegir las dos imágenes y capturar antes de enviarlas.
5. Guardar JPEG con estos nombres, revisar legibilidad y ausencia de datos
   privados, y comprobar que siguen viéndose correctamente en el README de GitHub.
